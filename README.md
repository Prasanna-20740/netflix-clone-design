# Netflix Clone Website 🎬

A Netflix-inspired website homepage created using HTML and CSS. This project recreates the look and feel of Netflix with a dark theme, movie posters, background images, and a clean user interface.

## 🚀 Features

- Netflix-inspired homepage design
- Dark-themed user interface
- Movie and series poster images
- Custom Netflix-style logo and branding
- Organized CSS styling
- Simple and user-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Image Assets (JPEG, PNG, WebP)

## 📂 Project Structure

```text
netflix-clone-design/
├── netflix.html
├── netflix.css
├── Logonetflix.png
├── Netflix-Logo-Font-2.webp
├── poster_squid_game.jpg
├── OIP.jpg
└── Other image assets
```

## 💻 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Prasanna-20740/netflix-clone-design.git
   ```

2. Open the project folder.
3. Open `netflix.html` in your web browser.

## 🎯 Project Purpose

The purpose of this project is to practice frontend web development skills, including HTML page structure, CSS styling, image integration, and website layout design.
